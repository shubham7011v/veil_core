# 🏆 BLUFF (Indian Style) — FINAL RULEBOOK v1

Status: LOCKED ✅

## 🎴 GAME SETUP
- **Players**: 2 to 10
- **Deck**: Standard 52 cards
- **Suits**: ❌ Ignored. Only Rank matters (A, 2–10, J, Q, K)
- **Cards distributed**: Equally
- **No eliminations**
- **Winner**: First player to reach 0 cards

## ▶️ GAME START
- **First player of a game**: Winner of previous game
- **At game start**:
    - ❌ No rank selected
    - ✅ First player:
        - Plays 1–4 cards
        - Declares a rank (truth or bluff)
        - Round begins

## 🔄 TURN RULES
On a turn, a player can:
- ▶️ **Play 1–4 cards**, OR
- ⏸️ **Pass**

**When playing**:
- Cards go face-down to center pile
- Player declares any rank
- Declared rank remains active until round ends

## 🧠 PASS RULES (VERY IMPORTANT)
- A player may pass any number of times
- **Passing**:
    - Adds no cards
    - Keeps bluff opportunity alive
    - Bluff opportunity moves forward with each pass

## 🔁 ROUND END VIA PASSING
### ✅ PASS-CYCLE END RULE
If all players pass and the turn comes back to the player who last played cards:
- 🗑️ Entire pile is **DISCARDED** (removed from game)
- 🔄 Round ends
- 🎴 That same player starts the next round
- 🆕 Player selects:
    - New cards (1–4)
    - New declared rank

## 🚨 BLUFF RULES
### Who can call Bluff?
- ✅ **Only the next active player in turn order**
- If player passes → bluff right transfers forward

### ⚖️ BLUFF CHECK
- Bluff applies to: ✅ **Only the LAST played cards**
- System checks: Do all those cards match the declared rank?

## 🔥 BLUFF OUTCOME (RESOLUTION)
### Case 1️⃣ — Bluff is CORRECT (Lie)
- 👉 Liar picks entire pile

### Case 2️⃣ — Bluff is WRONG (Truth)
- 👉 Caller picks entire pile

### After Bluff Resolution
- 🔄 Rank resets
- 🆕 New round starts
- ▶️ Next turn goes to the **winner** of the challenge (the one who was right)

## 🏁 LAST CARD RULE
- Bluff allowed on last card
- No auto-protection
- High-risk, high-reward

## 👀 VISIBILITY RULES
Players can see:
- ✅ Number of cards each player has
- ❌ Actual cards of others

## 🧩 COMPLETE ROUND FLOW (SIMPLE)
1. Player A plays cards → declares rank
2. Player B passes
3. Player C passes
4. Player D bluffs → check happens
**OR**
1. Everyone passes → turn comes back to Player A
2. Pile discarded
3. Player A starts new round
